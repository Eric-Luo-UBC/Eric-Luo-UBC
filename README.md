### [Classical Lane Detection](https://github.com/Eric-Luo-UBC/lane-detection)

A classical computer vision pipeline for road lane detection and image-space direction estimation using:

- HSV color segmentation
- Canny edge detection
- Probabilistic Hough Transform
- Geometric lane filtering
- Temporal smoothing

Developed as part of my research work at Tsinghua University.
